# Project brief

The original brief from the project owner, translated into English.

The goal is a compiled program that runs on any computer and shows the token usage of Anthropic Claude as live as possible, in a small tool window that acts as a status cockpit.

- It shows the 5-hour limit and the weekly limit in real time.
- It keeps itself as up to date as possible without being asked.
- It has a graphical visualisation that shows whether tokens are being used too fast or too slowly. The purpose of the tool is to use as many of the available tokens as possible while almost never running out. At any moment there should be an easy-to-read visualisation of whether usage is currently faster or slower than continuous, even usage.
- All available statistical data is displayed, and everything that can be derived from it is calculated and displayed.

The program must be usable on Windows, Linux and macOS without an installer. It must be a compiled executable and must be buildable for all common hardware, at minimum Windows on Intel, macOS on Apple M4, Linux on Intel, and Raspberry Pi.

Deliverables requested for the start:

- a concept document;
- a list of requirements.
