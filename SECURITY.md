# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through GitHub's **private vulnerability reporting**: open the repository's **Security** tab and choose **Report a vulnerability**.

You will receive an answer as soon as possible. Please include steps to reproduce and the affected version.

## Supported versions

There is no release yet. Once releases exist, only the latest release receives security fixes.

## Scope notes

The cockpit is designed to run locally and read usage data only. It must never store, log or display authentication credentials (requirement REQ-104). Reports about any deviation from this are especially welcome.
